# Gemini Instructions for SafeMap

Lee primero `AGENTS.md` y todos los `docs/*` que ahí se indican.

Respeta la arquitectura actual:
- HTML5
- CSS moderno
- JavaScript vanilla
- Leaflet.js
- CartoDB Dark Tile Layer
- localStorage

No migres a frameworks sin aprobación explícita.
No elimines funcionalidad existente ni inventes APIs que no existen.

Al finalizar cualquier tarea, actualiza `docs/HANDOFF_LOG.md` y agrega
pendientes nuevos a `docs/TASKS.md`.
